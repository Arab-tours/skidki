# Охота за скидками

Витрина самых выгодных предложений люксовых брендов из нескольких российских площадок. Каждое объявление сравнивается с медианой цены той же модели или того же типа вещи бренда; подозрительно дешёвое не скрывается, а помечается «⚠ Проверь».

## Источники

| Площадка | Что берём | Подлинность |
| --- | --- | --- |
| Oskelly | каталоги брендов по разделам (`data/sources.json` → `oskelly`) | ресейл с проверкой |
| The Cultt | каталоги брендов в сумках, обуви, аксессуарах + раздел sale | ресейл с проверкой |
| VIP Avenue | страницы брендов (скидки видны по зачёркнутой цене) | официальный магазин |
| Ozon | категории брендов | почти всегда реплики, помечаются |

Не собираем: ЦУМ, ЦУМ Collect, ЦУМ Outlet (robots.txt прямо запрещает ботов), Wildberries, Lamoda, Мегамаркет, Авито (антибот-защита), раздел /sale VIP Avenue (закрыт в robots.txt). Для них на сайте есть ссылки на поиск во вкладке «Площадки».

## Сборщик

```
python3 tools/scrape.py data/sources.json deals.json
```

- перед каждым запросом читает robots.txt площадки и пропускает запрещённое;
- представляется как `OkhotaZaSkidkami/1.0` со ссылкой на этот репозиторий, пауза 1,2 с между запросами к одному сайту;
- приводит размеры (INT/IT/EU/FR/RU/UK/US) к XXS…4XL и EU для обуви;
- считает медианы (The Cultt — по модели, остальные — по типу вещи бренда в том же состоянии), оценку выгоды `x` и пометки `f`;
- в `deals.json` попадают вещи с оценкой от `keep_min_score` и все помеченные.

Новый бренд: добавь его slug в `oskelly.brands`, `cultt.brands` и название в `vip.brands`.

## Заявки

«Заказать охоту» создаёт issue «Охота: …». Ежедневная задача добавляет бренд в источники, запускает сборщик, отвечает в issue лучшими ссылками и закрывает его.
