# Охота за скидками

Сайт с реальными объявлениями брендовой одежды со скидкой на российских площадках.

- **Находки** — объявления с ценой, старой ценой, размером и состоянием. Каждое сравнивается с медианой цены той же вещи того же бренда.
- **Фильтры** — бренды, раздел, пол, размер, цена, минимальная скидка, состояние, сортировка.
- **Заказать охоту** — заявка оформляется как issue с меткой `hunt`. Раз в день заявки обрабатываются, найденное добавляется в `deals.json`.
- **Поиск по площадкам** — переход в выдачу 30 площадок (Авито, Oskelly, ЦУМ, Ozon, Wildberries, Lamoda и др.) с подставленными фильтрами.

## Устройство

Статический сайт на GitHub Pages, без сборки.

- `index.html` — весь интерфейс.
- `deals.json` — данные: `{ updatedAt, feeds: [ { platform, brand, gender, cat, title, checkedAt, items: [ { p, o, s, cond, u } ] } ] }`.
  - `p` — цена, `o` — старая цена или `null`, `s` — размер, `cond` — `new` / `used`, `u` — ссылка на объявление.

Метки заявок: `hunt` — новая, `found` — найдено, `nothing` — пока ничего.

Брендовые вещи на маркетплейсах заметно дешевле магазинной цены часто оказываются репликами, поэтому в находки попадают площадки с проверкой подлинности.
