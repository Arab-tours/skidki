# Охота за скидками

Витрина люксовых вещей со скидкой: реальные объявления Oskelly с фото, фильтрами по брендам, типам, размерам одежды и обуви, цене, скидке и состоянию. Каждое объявление сравнивается с медианой цены той же вещи того же бренда в том же состоянии.

## Как устроено

- `index.html` — весь сайт, без сборки (GitHub Pages).
- `deals.json` — данные для сайта, собираются скриптом.
- `data/catalogs.json` — список каталогов Oskelly, за которыми следим (бренд, пол, раздел, ссылка).
- `data/raw/*.txt` — сырые строки каталога: `slug|цена|старая цена|размер|id фото`.
- `tools/build.py` — нормализует размеры (INT/IT/EU/FR/RU/UK/US → XXS…4XL и EU для обуви), считает медианы и пишет `deals.json`:

```
python3 tools/build.py data/raw deals.json
```

## Заявки

Заявка «Заказать охоту» — это issue с заголовком «Охота: …». Раз в день заявки обрабатываются: подходящий каталог добавляется в `data/catalogs.json`, issue получает комментарий и метку `found` или `nothing`.
